# RouteRadar-Bus-Utilization-Ridership-Analytics
An interactive Excel dashboard built to analyze bus transportation data and uncover operational insights for route optimization and resource planning.

# Key Metrics Tracked
Total Passengers: 6,587
Average Riders per Trip: 32.9
Busiest Route: East-West Express
Peak Hour of Operation: 8:57 PM

# Key Insights
1. 64.61% of total ridership occurs during PM hours vs 35.39% AM
2. Sunday and Monday are highest ridership days — accounting for 49.4% of weekly passengers
3. YoY ridership declined 83.5% — suggesting operational or demand-side issues requiring attention
4. 49% of buses are well-utilized; 25% underutilized — reallocation opportunity exists

# Tools Used
Excel — Pivot Tables, Charts, Conditional Formatting, KPI Cards
